🏦 Overview

A modern, responsive banking application user interface built with React.js and Tailwind CSS. Features a clean design with glassmorphism effects, smooth animations, and a fully responsive layout.
✨ Features

    Modern UI/UX design with gradient effects
    Fully responsive across all devices
    Reusable React components
    Tailwind CSS for styling
    Optimized performance with Vite
    Clean and maintainable code structure

🚀 Quick Start

Bash

# Clone the repository

git clone https://github.com/AydinHabibi1991/BankUI.git

# Navigate to project directory

cd bank-system-ui

# Install dependencies

npm install

# Start development server

npm run dev

# Build for production

npm run build

🛠️ Tech Stack

    React.js - Frontend library
    Tailwind CSS - Utility-first CSS framework
    Vite - Build tool
    JavaScript - Programming language
